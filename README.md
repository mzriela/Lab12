# Lab12
In this lab I learned how the ESP32 reads and makes analog signals. I read a potentiometer with the ADC, sampled a sine wave to see aliasing, and used the DAC and PWM to output voltages. I also used an RC filter to turn PWM into a steady voltage.
# Required Equipment
-	ESP32 Development Board (Espressif ESP32-DevKitC)
-	10 kΩ potentiometer
-	LED and 220 Ω resistor
-	RC filter: 10 kΩ resistor, 1 µF capacitor and 10 µF capacitor
-	1 kΩ resistor (protects the ADC pin from the signal generator)
-	Signal (function) generator
-	Digital multimeter
-	Breadboard
-	Jumper Wires
-	USB Cable
# Software 
-	Visual Studio Code
-	PlatformIO
-	Serial Monitor
-	Teleplot extension for VS Code (the Serial Plotter used in this lab)
-	lab11_starter_main.cpp file (provided by my instructor)
